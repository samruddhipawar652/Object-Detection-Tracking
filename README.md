# CodeAlpha_ObjectDetectionTracking

## Project Overview

This project is developed as part of the CodeAlpha Artificial Intelligence Internship.

The system performs real-time object detection and tracking on video input using Computer Vision techniques. It identifies objects such as people, cars, bicycles, buses, and other common objects and displays bounding boxes around them.

## Features

- Real-time object detection
- Object classification
- Bounding box visualization
- Video file processing
- Detection of multiple object categories
- OpenCV-based implementation

## Technologies Used

- Python
- OpenCV
- NumPy
- Computer Vision
